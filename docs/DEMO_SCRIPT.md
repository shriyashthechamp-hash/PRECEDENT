# PRECEDENT — 90-120 Second Live Demonstration Script

## Narrative
"Every bid builds a better next bid. Traditional proposal tools store answers. PRECEDENT remembers *why* answers were corrected, alerts you when you contradict earlier commitments, and makes organizational intelligence compound."

---

### Scene 1: The Problem & The Command Center (0:00 - 0:20)
- **Visual**: Navigate to **Overview Dashboard**.
- **Action**: Highlight active proposals, contradictory claim alerts, and the Hindsight memory stream.
- **Narrative**: "Proposal teams constantly repeat the same mistakes because generic AI forgets human review edits. Here is PRECEDENT's live intelligence command center."

### Scene 2: RFP Ingestion & First Proposal Review (0:20 - 0:45)
- **Visual**: Open Proposal #1 (Enterprise Healthcare RFP) in **Review Center**.
- **Action**: Select Question: *Support Availability & Escalation*.
- **Observation**: Base AI originally drafted: *"We provide 24/7 dedicated support for all tiers."*
- **Interaction**: Reviewer edits to: *"Our enterprise support is available 24/5. Emergency escalation for P1 incidents is available 24/7."*
- **Reason Entered**: *"Original statement overstated standard tier coverage."*
- **Click**: `Approve & Retain Memory`.
- **System Action**: PRECEDENT synchronously updates the Claim Ledger and retains the verified memory in Hindsight.

### Scene 3: Proposal #2 — Instant Recall in the Same Sector (0:45 - 1:05)
- **Visual**: Switch to Proposal #2 (Fintech Health RFP).
- **Action**: Generate answer for *Support SLAs & Tiers*.
- **Result**: The AI instantly pulls the Hindsight precedent! The generated text automatically includes the approved 24/5 wording with 24/7 P1 escalation, citing the reviewer reason from Proposal #1.
- **Reviewer**: 0 edits required. Reviewer edit reduction achieved.

### Scene 4: Contradiction Detection & Claim Ledger (1:05 - 1:25)
- **Visual**: Navigate to **Contradiction Center**.
- **Action**: Inspect active conflict alert on *Data Retention Policy*.
- **Conflict**: 
  - *Current Claim*: "Customer data retained for 90 days post termination."
  - *Approved Precedent (Claim #CLM-019)*: "Customer data deleted within 30 days per HIPAA compliance addendum."
- **Provenance**: Shows exact originating proposal, approver, and date.
- **Resolution**: Click `Enforce Approved Precedent` or `Submit Approved Exception`.

### Scene 5: Memory ON vs Memory OFF A/B Laboratory (1:25 - 1:45)
- **Visual**: Open **Memory A/B Lab**.
- **Action**: Run side-by-side generation for *Disaster Recovery & RTO/RPO*.
- **Memory OFF**: Vague generic answer (RTO: 1 hour, RPO: 15 min without caveats), 4 missing compliance nuances, high edit burden.
- **Memory ON**: Retrieves verified DR tier architecture, cites SOC2 Type II audit report, aligns with approved claims, 0 contradictions, measured 75% edit reduction.

### Scene 6: Institutional Reflection (1:45 - 2:00)
- **Visual**: Open **Intelligence Explorer** -> `Reflect`.
- **Output**: Higher-order synthesis: *"Healthcare evaluators penalize vague 24/7 claims. Proposals specifying tiered escalation SLAs have a 92% approval rate."*
- **Closing**: "Documents are inputs. Experiences and outcomes are the intelligence."
